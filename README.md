# 四川旅游全攻略

一个单页面的四川旅游规划网站，覆盖成都（11景）、阿坝州（6景）、乐山（6景）共 23 个景点。

## 功能

- 自选景点：左侧勾选想去的景点，一键生成个性化游玩路线
- 智能路线推荐：按城市分组 + 最近邻算法，自动排序最短交通路径
- 详细景点信息：每个景点包含描述、必看亮点、门票价格、运营时间、建议时长
- 结构化交通：地铁几号线什么站、公交线路、打车费用、自驾路线分列显示
- 四季天气：三个城市按春/夏/秋/冬展示温度、降水和游玩建议
- 实用锦囊：美食推荐、省钱攻略、装备清单、健康安全贴士
- 费用预估：自动计算所选景点的门票总额和建议天数
- 响应式设计：手机和桌面均可流畅浏览

## 快速部署（GitHub Pages）

### 方法一：Fork 部署
1. Fork 本仓库到你的 GitHub 账号
2. 进入 Settings -> Pages -> Source 选择 main 分支 -> Save
3. 几分钟后访问 https://你的用户名.github.io/仓库名/

### 方法二：手动上传
1. 在 GitHub 新建仓库（如 sichuan-travel）
2. 上传 index.html 和 README.md 到仓库根目录
3. Settings -> Pages 启用，选择 main 分支

### 方法三：本地使用
下载 index.html，双击即可在浏览器中打开使用，无需任何服务器。

## 技术栈

- 纯 HTML + CSS + JavaScript，零依赖
- 数据内嵌为 JSON，无需后端
- 贪心最近邻算法优化景点游览顺序
